# Molecular Docking of Candidate Inhibitors Against Calpain

This repository contains the molecular docking results for a virtual screening study evaluating two candidate compounds (PubChem CID 2974355 and CID 6915837) against **calpain**, benchmarked against the known calpain inhibitor **MDL28170 (Calpain Inhibitor III / ALLN)** as a reference ligand.

Docking was performed using **AutoDock Vina**, and the resulting protein–ligand complexes were visualized and analyzed for binding-site interactions using **BIOVIA Discovery Studio Visualizer**.

> Note: file and folder names below match the original output files exactly, so results can be traced back to the source docking run. Descriptions below explain what each one contains.

---

## Repository Structure

```
calpain-molecular-docking/
├── receptor/                 # Prepared target protein
├── ligands/                  # Docked ligand poses (Vina output)
├── complexes/                # Protein + best-pose ligand, merged for visualization
├── interaction_analysis/     # 2D/3D interaction diagrams and DSV session
└── results_summary.md        # Binding affinity comparison table
```

## 1. `receptor/`
| File | Description |
|---|---|
| `protein_vina.pdbqt` | The calpain receptor structure, prepared (polar hydrogens added, Gasteiger charges assigned, non-polar hydrogens merged) for AutoDock Vina docking. This is the fixed target used in every docking run below. |

|---|---|---|
| `MDL28170_docked.pdbqt` | MDL28170 — reference/standard calpain inhibitor (Calpain Inhibitor III, ALLN) | **-6.7** |
| `CID_2974355_docked.pdbqt` | Candidate compound, PubChem CID 2974355 | **-7.2** |
| `CID_6915837_docked.pdbqt` | Candidate compound, PubChem CID 6915837 | **-6.9** |

## 3. `complexes/`
The receptor (`protein_vina.pdbqt`) merged with the **top-ranked (Model 1) pose** of each ligand, exported as a single PDB file for visualization and interaction analysis in Discovery Studio Visualizer.

| File | Corresponding Ligand |

| `Complex_1.pdb` | Calpain + CID_6915837 (best pose) |
| `Complex_2.pdb` | Calpain + CID_2974355 (best pose) |

## Methodology (summary)

1. **Target preparation**: Calpain receptor structure cleaned (waters/heteroatoms removed) and converted to PDBQT format for AutoDock Vina (`receptor/protein_vina.pdbqt`).
2. **Ligand preparation**: 3D structures of MDL28170, CID 2974355, and CID 6915837 prepared and converted to PDBQT with Gasteiger charges.
3. **Docking**: AutoDock Vina used to dock each ligand into the calpain binding site, generating 9 poses per ligand ranked by predicted binding affinity (`ligands/`).
4. **Complex generation**: Best-scoring pose for each ligand combined with the receptor into a single PDB complex (`complexes/`).
5. **Interaction analysis**: Complexes loaded into BIOVIA Discovery Studio Visualizer to identify key binding-site residues and interaction types (H-bonds, hydrophobic contacts), exported as 2D/3D images (`interaction_analysis/images/`).

See [`results_summary.md`](results_summary.md) for the full results table.

## Requirements to reproduce / view
- [AutoDock Vina](http://vina.scripps.edu/) — docking
- [AutoDockTools / MGLTools](https://ccsb.scripps.edu/mgltools/) — receptor/ligand `.pdbqt` preparation
- [BIOVIA Discovery Studio Visualizer](https://www.3ds.com/products/biovia/discovery-studio/visualization) (free) — to open `.dsv` and re-render complexes
- Any standard molecular viewer (PyMOL, Chimera, VMD) can also open the `.pdb` and `.pdbqt` files
