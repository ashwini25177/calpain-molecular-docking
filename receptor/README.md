# receptor/

`protein_vina.pdbqt` — Calpain-1 (human, PDB 8GX3) receptor, chain A residues 32–358, prepared for AutoDock Vina: co-crystallized ligand (KJ0) and waters removed, polar hydrogens added, Gasteiger charges assigned, the 2 structural Ca²⁺ ions retained. Used as the fixed target for every docking run in `../ligands/`.
